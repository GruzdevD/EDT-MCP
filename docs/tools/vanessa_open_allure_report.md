# vanessa_open_allure_report

Generate and open the Allure report of a Vanessa Automation BDD run. Address the run by launchId (from vanessa_run_feature) or absolute outDir. Generates the static report from the raw Allure results via the allure commandline, serves it over loopback and opens it in the in-EDT Allure Report view (or the OS browser when detached). Parameters and examples: get_tool_guide('vanessa_open_allure_report').

## Parameters
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| launchId | — | integer | A launchId from vanessa_run_feature whose out dir is used. Either this or outDir is required. |
| outDir | — | string | Absolute out dir of the run. Either this or launchId is required. |
| resultsDir | — | string | Override the raw Allure results dir (default: the out dir's allure subdir, or the Preferences setting). |
| reportDir | — | string | Override the dir the generated report is placed in (default: sibling of the results dir, or the Preferences setting). |
| detached | — | boolean | Open in the OS browser instead of the in-EDT view. Default false. |
| allureBin | — | string | Override the allure commandline path (otherwise env.sh ALLURE_BIN, ~/.1c-tools/allure, PATH). |
| generate | — | boolean | Generate the report before opening. Default true; false expects an existing allure-report dir. |

## Guide
Generates and opens a report from the raw Allure results of a Vanessa Automation run. The report is served over loopback on the EDT host.

## Parameters

- `launchId` — ID from `vanessa_run_feature` or `vanessa_run_by_tags`.
- `outDir` — Absolute output directory of the run. Provide this or `launchId`. If both are supplied, `outDir` takes precedence.
- `resultsDir`, `reportDir` — Optional overrides for the raw Allure results and the generated HTML report directories.
- `allureBin` — Optional Allure CLI path. The default lookup uses the project configuration, the local Allure installation, and the process PATH.
- `generate` defaults to true. Set it to false to reuse a report with an existing `index.html`. The raw results directory still needs to be available.
- `detached` defaults to false, which opens the EDT Allure Report view. Set it to true to open the operating system browser.

## Examples

```text
vanessa_open_allure_report(launchId: 42)
vanessa_open_allure_report(launchId: 42, generate: false, detached: true)
```

The result includes the report and results directories, local URL, port, and display mode. Enable Allure output for the run if the raw results are missing.
