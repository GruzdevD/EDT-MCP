# vanessa_run_by_tags

Launch a Vanessa Automation BDD run limited to scenarios/features carrying a given tag (sets the VAParams tag filter, generates the run artifacts, and starts VA_Runner on the project's EDT launch configuration). Returns a launchId for vanessa_get_execution_status / vanessa_get_test_report, like vanessa_run_feature. Parameters and examples: get_tool_guide('vanessa_run_by_tags').

## Parameters
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| project | yes | string | Project key whose env.sh drives the run, e.g. 'afm' (see ~/.1c-tools/vanessa/projects/<project>/env.sh). |
| tags | yes | string | Comma/space separated Vanessa tags to run, e.g. 'smoke,regress' (VAParams СписокТеговОтбор). |
| featureDir | — | string | Feature file or directory to scope the tag search to. Defaults to the project's FEATURES_DIR. |
| launchConfigurationName | — | string | Exact name of the EDT launch configuration that starts the 1C client. Defaults to the project's EDT_LAUNCH from env.sh. |

## Guide
Launches a Vanessa Automation BDD run limited to the scenarios/features of a project that carry a given tag. Thin wrapper over the same launch pipeline as `vanessa_run_feature`: it pre-fills the VAParams tag filter (`СписокТеговОтбор`) from the `tags` parameter, generates the run artifacts, and starts `VA_Runner` on the project's EDT launch configuration. Returns a `launchId` consumable by `vanessa_get_execution_status` / `vanessa_get_test_report`, exactly like `vanessa_run_feature`.

## When to use

Run a whole tagged slice (e.g. a `smoke` set) without listing features manually. Discover available tags first with `vanessa_list_features`.

## Parameter details

- `project` (required) — the project key whose `env.sh` drives the run, e.g. `afm` (see `~/.1c-tools/vanessa/projects/<project>/env.sh`).
- `tags` (required) — comma/space separated Vanessa tags to run, e.g. `smoke,regress` (maps to VAParams `СписокТеговОтбор`).
- `featureDir` (optional) — a feature file or directory to scope the tag search to; defaults to the project's `FEATURES_DIR`.
- `launchConfigurationName` (optional) — the EDT launch configuration that starts the 1C client; defaults to the project's `EDT_LAUNCH`.

## Example

```
vanessa_run_by_tags(project: "afm", tags: "smoke")
```

Returns `{launchId, project, feature, tags, configuration, status, outDir, junitReportPath}`.

## Errors

- `project is required.` / `tags is required.` — missing required input.
- No config — the project `env.sh` is missing.
- Launch failures return the underlying `LaunchTool` error JSON; the run handle is still registered so `vanessa_get_execution_status` can report the failure.
