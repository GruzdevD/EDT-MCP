# EDT-MCP Dev Studio & Eclipse Debugger

Interactive development environment setup, Eclipse `.launch` debug configuration generator, and MCP protocol inspector for 1C:EDT plugin development.

## Features

- **Eclipse Debug Configurator**: Generates PDE/OSGi launch configurations (`.launch` XML) tailored for EDT plugin debugging.
- **MCP Proxy & Protocol Inspector**: Real-time tool execution, schema explorer, and request/response inspection.
- **Specter Integration**: Ready-to-use connection templates and automated test execution bridges.
- **AI Assistant**: Troubleshooting and knowledge base for Tycho, OSGi bundles, and 1C:EDT architecture.

## Quick Start

```bash
cd studio
npm install
npm run dev
```

Server will run on `http://localhost:3000`.
