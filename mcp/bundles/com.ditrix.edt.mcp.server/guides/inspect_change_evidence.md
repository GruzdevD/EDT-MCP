# inspect_change_evidence

Use the same repoId, projectName, branch and changeId as the build. With view=receipts recover planId, parent, tree, commit and journal phase. Retry confirm with the original planId for an interrupted transaction. Build receipts are retained for seven days. An expired unconfirmed preview must be recreated.

Pass the original cycle and view=list to discover jobs after reconnecting. Read view=job for environment, ordered inputs, selectors, terminal outcome and reportDigest. Only FAILED and BROKEN can establish the first red baseline. UNKNOWN requires a fresh job. For each of production, tests and documents request view=files, then view=content with the listed digest. Concatenate decoded base64 chunks until complete. For view=compare supply baseline jobId, group and reachable targetSha. For documents, supply either a reachable targetSha or the exact current documentRevisions. Follow nextCursor with identical parameters. A revoked grant or expired reservation stops the review.

A cycle with only expired jobs returns a retention error. If retained and expired jobs coexist, the list reports incomplete history. The original red baseline cannot be replaced after expiry. Comparison keeps explicit dependency commits pinned.
