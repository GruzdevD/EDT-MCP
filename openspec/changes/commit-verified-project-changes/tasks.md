- [ ] 1.1 Разрешать `entryId` через контракт снимка и строить план JGit от ожидаемого родителя; временный репозиторий подтверждает правильный tree ID для add/modify/delete/rename без изменения индекса и ветки.
- [ ] 1.2 Ограничить план текущей разрешённой веткой и одним репозиторием; проверить отказ на detached HEAD, неверную область, конфликт, частичную индексацию и обязательную внешнюю политику. Описать ограничения в guide предпросмотра.

## 2. Подтверждение и восстановление

- [ ] 2.1 Связать planId с владельцем, TTL и точным содержимым; тестами проверить отказ без права записи, при отказе в согласии, отзыве права и замене файла между вызовами.
- [ ] 2.2 Записывать выбранное дерево, обновлять ожидаемый ref и только выбранные записи индекса; интеграционный тест проверяет родителя, diff, сохранность чужих staged/unstaged и отсутствие записи при смене ветки.
- [ ] 2.3 Журналировать операцию до изменения ref и восстанавливать результат после потери ответа; тест с искусственным прерыванием между ref и индексом подтверждает один SHA, сохранность последующих правок и явное `recovery_required` при конфликте.
- [ ] 2.4 Зарегистрировать раздельные инструменты и право подтверждения; обновить guide с примерами ошибок и повтора. Проверить вызовы по имени с отключённым `git(command)` и соответствие схем примерам.
